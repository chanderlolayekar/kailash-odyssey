# Kailash Odyssey

An interactive web exploration of the sacred Mount Kailash pilgrimage (*kora*) and the surrounding Himalayan landscape—combining spatial mapping, route waypoints, and cultural context in a standalone open-source web application.

- **Live App:** [Explore Kailash Odyssey](https://chanderlolayekar.github.io/kailash-odyssey/)
- **Source Repository:** [github.com/chanderlolayekar/kailash-odyssey](https://github.com/chanderlolayekar/kailash-odyssey)

---

## Features

- **Interactive Map & Waypoints:** Explore key sacred sites, high-altitude passes (including Dolma La), monasteries, and Lake Manasarovar along the Kailash circuit.
- **Guided Pilgrimage Context:** View historical, geographic, and cultural notes tied directly to stops along the route.
- **Standalone Open-Source Architecture:** Runs entirely in the browser with no proprietary backend or API keys required.

---

## Tech Stack

- **Frontend:** React 18, Vite 6, React Router
- **Mapping & Visualization:** Leaflet, React Leaflet, Three.js
- **UI & Styling:** Tailwind CSS, Radix UI, Framer Motion, Lucide Icons
- **Deployment:** GitHub Actions & GitHub Pages
